    Enumeration JsonMsgTypeConst

    Enumeration of the message type ID's associated with different JSON message data types. The static ID fields of the individual JSON message types are initialized to these enumeration names. Whenever a new JSON message type is added to the system, an associated entry must be added to the enumeration. IMPORTANT: The enumeration name MUST match the message type ID value due to a limitation of the typeScript-generator which only translates the name of the enumeration not its value.

    Values:

    • addType - JsonAddTypeData
    • availableTypes - JsonAvailableTypesData
    • ballData - JsonBallData
    • canvasDim - JsonCanvasDimData
    • clearBalls - Clear the balls in the backend system, no data associated with this message.
    • combineTypes - JsonCombineTypesData
    • createType - JsonData
    • initSystem - Initialize the backend system, no data associated with this message.
    • nextType - Change the currently instantiated types to their next type. No data associated with this message.
    • point2D - JsonPoint2DData
    • port - JsonPortData
    • startAnimation - Start animation message, no data associated with this message.
    • stopAnimation - Stop animation message, no data associated with this message.
    • status - JsonStatusData
    • text - JsonTextData
    • update - JsonUpdateData
    • updateInterval - JsonUpdateIntervalData
    • updateTask - JsonUpdateTaskData
    • taskUpdated - JsonTaskData
    • deleteTask - JsonDeleteTaskData
    • taskDeleted - JsonDeleteTaskMsg
    • taskData - JsonTaskData
    • updateTaskAssignees - JsonUpdateTaskAssigneesData
    • taskAssigneesUpdated - JsonTaskOperationStatusMsg
    • DEFAULT - Message type associated with unknown or default message types. Not associated with any known message data type.
